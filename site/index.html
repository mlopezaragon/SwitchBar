01 — The problem

You find out you are out of usage the moment Claude Code stops answering. Two accounts, three windows each, and no way to see any of it. SwitchBar puts all of it in one place.

Under 75 %

Plenty of room. Blue bar, nothing to do.

75 % and up

90 % and up

Personal cap

03 — What it does

Small app.
Few opinions. All of them useful.

Three windows per account

The 5-hour window, the weekly window and the separate Opus weekly quota — each with the exact time it resets, not a guess.

Thresholds you choose

Independent limits per window. Automatic switching only fires where you want it to.

Shared accounts

Set a personal cap — say 70 % — and SwitchBar treats the account as spent early, leaving margin for whoever shares it.

Your choice wins

Pick an account by hand with /login and automatic switching pauses for 15 minutes. No app should argue with you.

Anthropic status, inline

Incidents from status.claude.com appear in the panel, so an outage on their side is never mistaken for a problem on yours.

Undo, always

Every switch is reversible from the panel. Claude Code's own session data — MCP credentials and every other key in ~/.claude.json — is preserved untouched.

Read this before you rely on it

SwitchBar talks to the same private endpoints Claude Code itself uses, with Claude Code's own public client id. Those endpoints are not a documented, stable public API, and Anthropic may change or restrict them at any time. The app is built to fail safely when that happens — it keeps the last known data, never corrupts your Claude Code session, and marks accounts that need a new login — but no permanent compatibility can be promised. Login itself always runs through the official claude auth login --claudeai flow in your terminal: SwitchBar never sees your password.

05 — Install

One line, and it's in your bar.

$ brew install --cask mlopezaragon/tap/switchbar

Or by hand

Download SwitchBar-<version>.dmg from GitHub Releases, check its published SHA-256 with shasum -a 256, and drag the app to Applications.

Releases ↗

Then

Click “Add account”, sign in once through the official Claude Code flow, and repeat for each account. From then on, switching never asks for a login while the session stays valid.

Requirements

macOS 26 (Tahoe), Apple Silicon or Intel — one universal, Developer ID signed binary. Claude Code with one or more Pro/Max accounts. Beta builds are not notarized yet: right-click, then “Open”, the first time.
