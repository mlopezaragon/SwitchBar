Live usage for every account.

SwitchBar shows the 5-hour, weekly and Fable windows for each Claude Code account in the macOS menu bar, and switches the active account before a limit stops you.

$brew install --cask mlopezaragon/tap/switchbar
Download DMG

macOS 14 (Sonoma) or later · Universal binary · Claude Code with Pro or Max accounts

The panel

Every account, every window.

Each account lists its 5-hour window, its week, and the separate Fable weekly quota, with the time each one resets. Cross a threshold and the active account moves on its own.

Three things it does.

Automatic switching

Set a threshold per window, per account. When one fills up, SwitchBar makes the next account active — no password, no browser, no new login. Open terminals keep working, and one click undoes it.

Instant visibility

Every account and all three windows in one panel, each with its reset time. Anthropic incidents from status.claude.com appear inline, so an outage on their side is never mistaken for a problem on yours.

Private by design

Tokens stay in the macOS Keychain and never leave the machine. No telemetry, no analytics, no third-party server — only usage reads against Anthropic's own endpoints.

Install

One command.

$brew install --cask mlopezaragon/tap/switchbar
Requirements
macOS 14 (Sonoma) or later, Apple Silicon or Intel. Claude Code with one or more Pro/Max accounts.
Manual install
Download the DMG from Releases, verify its published SHA-256, then drag SwitchBar to Applications. The app is notarized by Apple and opens without a Gatekeeper prompt.
First run
Add each account once through the official Claude Code login flow. Switching never asks again while the session stays valid.
Updates
SwitchBar checks a signed appcast and installs new versions in place.
